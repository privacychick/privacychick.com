Two-Factor Authentication

Add a second lock to your accounts. Two-factor authentication helps protect you if your password is stolen.

How to set up 2FA in 5 steps

  1. 1

    Choose where to keep your codes

    My first choice: Proton Authenticator. Install the free app from the App Store (iPhone) or Google Play (Android). No Proton account is needed.

    Already use Bitwarden? Its Password Manager can generate codes inside your vault with Premium or Families. Check the paid plans. This is different from the free, separate Bitwarden Authenticator app.

  2. 2

    Go to your account’s security settings

    Log in to the account you want to protect (your bank, email, Amazon, etc.) and look for Security or Two-Factor Authentication in the settings menu.

  3. 3

    Choose “Authenticator App”

    Choose Authenticator App rather than SMS/text message when offered. The site will show you a QR code, usually with an option to see a manual setup key.

  4. 4

    Add the account to your chosen app

    Proton: tap + and scan the QR code, or enter the site’s manual setup key.

    Bitwarden: edit that site’s saved login. Choose Set up TOTP on mobile, or the TOTP scanner in the browser extension, to scan the QR code. Or paste the manual setup key into the Authenticator key field. Save the login.

  5. 5

    Confirm setup and save your backup codes

    Back on the site, enter the current 6-digit code from your chosen app and finish the setup. Wait for the site to confirm that 2FA is on. If a code expires, use the next one.

    Save any backup codes the site provides. A printed copy in a secure place is a good option. Your password manager can hold other accounts’ backup codes, but keep Bitwarden’s own recovery code outside its vault so you can reach it if you are locked out.

⚠
Using Bitwarden for codes? Protect it separately

Use a strong, unique master password and turn on Bitwarden’s own two-step login with a separate app such as Proton Authenticator, or a FIDO2 security key. Do not keep its only login code source inside the vault. Print its recovery code and keep it somewhere secure outside Bitwarden. That code does not replace a forgotten master password.

💡
Start here

Set up 2FA on your most important accounts first: email, bank, and any account that stores payment information. Then work your way through the rest.

⚠
Avoid SMS (text message) 2FA when possible

If a site only offers to send a code by text message, that’s better than nothing, but it’s the weakest form of 2FA. Hackers can intercept texts through a technique called SIM swapping. Use an authenticator app whenever the option is available.

What is two-factor authentication?

Two-factor authentication (2FA), sometimes called two-step verification or multi-factor authentication, adds protection beyond a password. A stolen password alone is usually not enough to sign in because the site also asks for a second check, such as an authenticator code.

Think of it like a bank safe that requires both a key and a combination. Stealing one isn’t enough.

The “factors” in authentication are typically described as:

  • Something you know: your password
  • Something you have: your phone (with an authenticator app)
  • Something you are: a fingerprint or face scan

2FA combines at least two of these. The most common combination is your password plus a time-sensitive code generated by an app on your phone.

Why passwords alone aren’t enough

Passwords can be exposed in data breaches, stolen through fake login pages, or guessed. A strong, unique password matters, but a second login check adds protection if that password is stolen.

2FA is not a guarantee. A fake login page can steal your password and current authenticator code together, and a compromised device can expose both.

Login security options

Not all login methods offer the same protection. Authenticator codes are a practical improvement over texts, but TOTP codes are not phishing-resistant: a fake site can trick you into sharing a code and use it straight away. FIDO2 security keys and passkeys resist that kind of trick.

Method How it works Strength
SMS / Text message A 6-digit code is sent to your phone number Weak (vulnerable to SIM swapping)
Email code A code is sent to your email address Depends on your email security; can be phished
Authenticator app (TOTP) App usually generates a new 6-digit code every 30 seconds Good everyday option; can be phished
FIDO2 hardware security key A physical USB or NFC key you plug in or tap Phishing-resistant; best for high-value accounts
Passkeys Often replaces a password and code; confirm with your device or password manager Phishing-resistant where supported

A note on passkeys

Passkeys often let you sign in without a password and code. You confirm the login with your fingerprint, face, device PIN, or password manager. A passkey is tied to the real site, so a lookalike site cannot use it.

The site stores only the public part of a passkey, not the secret needed to sign in. Some passkeys stay on one device or security key; others sync through an encrypted password manager. Your password manager (e.g., Bitwarden) can store passkeys alongside your passwords.

Choose a passkey when available, and check the site’s recovery options before relying on it. You’ll still need authenticator codes for many sites.

Why I recommend Proton Authenticator

I recommend Proton Authenticator because it combines strong privacy with ease of use:

  • Separate from your password vault: opening your password manager does not also reveal codes kept only in Proton Authenticator
  • Encrypted sync: optional cross-device sync protects your authenticator data with end-to-end encryption
  • No account required: works fully offline; a Proton account is only needed if you want to sync across multiple devices
  • Open-source: the code is publicly auditable, so security researchers can verify it does what it claims
  • Cross-platform: available on iPhone, Android, Windows, Mac, and Linux
  • Free: no cost, no ads, no data selling

If you use optional sync, Proton Authenticator encrypts your authenticator data before it leaves your device. Proton cannot read that synced data. This protection does not prevent someone with access to your unlocked device from seeing your codes.

Already use Bitwarden? A convenient second choice

Bitwarden can keep a site’s password and authenticator key in the same saved login. That key, also called a secret or seed, creates the changing two-step codes. You do not need to switch between two apps to find them.

Generating codes inside Password Manager is paid: you need Premium or membership in a paid Families, Teams, or Enterprise plan. Families includes premium features for up to six people. Free Password Manager accounts can save the key but cannot generate the codes there. See current Bitwarden plans.

The standalone Bitwarden Authenticator is a different, free iPhone and Android app. You can use it without a Password Manager account. It does not make the built-in Password Manager feature free.

Where code filling works

Bitwarden’s browser extension on a computer and its iPhone/iPad app on iOS 18 or later can fill codes in supported login forms. If browser “autofill on page load” is enabled, the code is copied for pasting instead. Filling depends on the site and your settings.

On Android, the desktop app, or a form that does not support code filling, open the saved login, copy the current code, and paste or type it. All Bitwarden apps can display and copy codes. The official setup guide explains the options.

Why you might keep codes separate

If an attacker can read your vault, they can get both your passwords and the secret keys that generate future codes. Keeping codes in Proton Authenticator avoids putting both in one vault. It does not make a compromised phone or computer safe.

For your most important accounts, I prefer a separate authenticator, or a FIDO2 security key or passkey where available. Built-in Bitwarden codes can still be a sensible convenience choice if that helps you use two-step login consistently. Neither Bitwarden nor Proton’s changing codes are phishing-resistant.

Protect Bitwarden itself separately. Use a strong, unique master password and a separate authenticator or FIDO2 security key for its two-step login. Keep an independently saved recovery code, such as a printed copy in a safe place. Do not store the only copy inside the locked vault you would need it to recover.
